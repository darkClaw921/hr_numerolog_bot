# Бот для нумерологических расчетов

Telegram бот на aiogram для выполнения нумерологических расчетов по дате рождения.

## Установка

1. Клонируйте репозиторий или скачайте файлы проекта.

2. Установите зависимости:
```bash
uv sync
```

3. Создайте файл `.env` в корне проекта:
```
BOT_TOKEN=your_telegram_bot_token_here
```

Для получения токена:
- Откройте [@BotFather](https://t.me/BotFather) в Telegram
- Отправьте команду `/newbot`
- Следуйте инструкциям для создания бота
- Скопируйте полученный токен в файл `.env`

## Запуск

```bash
uv run main.py
```

## Использование

1. Найдите вашего бота в Telegram по имени, которое вы указали при создании
2. Отправьте команду `/start`
3. Отправьте дату рождения в формате `DD.MM.YYYY` (например, `18.08.1984`)
4. Бот выполнит расчеты и выведет результаты

## Команды

- `/start` - Начать работу с ботом
- `/help` - Показать справку

## Что рассчитывает бот

1. Первое дополнительное число (сумма всех цифр даты)
2. Второе дополнительное число (сумма цифр первого)
3. Третье дополнительное число (по специальной формуле)
4. Четвертое дополнительное число (сумма цифр третьего)
5. Матрица (секторы 1-9) с распределением чисел
6. Коэффициенты секторов:
   - Плотское (секторы 3/5/7)
   - Быт (секторы 4/5/6)
   - Цель (секторы 1/4/7)
   - Семья (секторы 2/5/8)
7. Число Судьбы
