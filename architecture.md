## Описание компонентов

### main.py
Точка входа приложения:
- Добавляет корневую директорию проекта в `sys.path` для корректной работы абсолютных импортов
- Импортирует и запускает функцию `main()` из `src.bot`
- Используется для запуска бота через `uv run main.py`

### src/bot.py
Основной файл с логикой бота. Содержит функцию `main()` для запуска бота:
- Инициализирует экземпляр бота с токеном из конфигурации
- Создает диспетчер (Dispatcher) для обработки сообщений
- Регистрирует роутеры с обработчиками
- Запускает polling для получения обновлений от Telegram API

### src/config.py
Модуль конфигурации:
- Загружает переменные окружения из файла `.env` с помощью `python-dotenv`
- Экспортирует `BOT_TOKEN` для использования в других модулях
- Выбрасывает ошибку, если токен не найден

### src/handlers/commands.py
Обработчики команд и сообщений бота:
- `cmd_start()` - обработчик команды `/start`, приветствует пользователя
- `cmd_help()` - обработчик команды `/help`, показывает справку
- `process_date()` - обработчик даты рождения в формате DD.MM.YYYY, выполняет расчеты и отправляет результаты (основные результаты и дополнительные качества отправляются отдельными сообщениями)
- `format_results()` - форматирует результаты расчетов для красивого вывода пользователю, включает интерпретации секторов
- `format_additional_qualities()` - форматирует дополнительные качества для вывода отдельным сообщением

### src/utils/numerology.py
Модуль с логикой нумерологических расчетов:
- `parse_date()` - парсит строку даты в формат (день, месяц, год)
- `sum_digits()` - суммирует цифры числа до получения однозначного
- `calculate_first_additional()` - вычисляет первое дополнительное число (сумма всех цифр даты)
- `calculate_second_additional()` - вычисляет второе дополнительное число
- `calculate_third_additional()` - вычисляет третье дополнительное число по формуле
- `calculate_fourth_additional()` - вычисляет четвертое дополнительное число
- `fill_matrix()` - заполняет матрицу (секторы 1-9) числами из даты и дополнительных чисел
- `calculate_sector_coefficient()` - вычисляет коэффициент сектора как сумму количества цифр в указанных секторах
- `calculate_destiny_number()` - вычисляет Число Судьбы (может быть 11 - мастер-число, иначе приводится к однозначному)
- `calculate_all()` - главная функция, выполняет все расчеты и возвращает полный результат

### src/utils/interpretations.py
Модуль с интерпретациями секторов матрицы Пифагора на основе коэффициентов:
- `get_character_interpretation()` - интерпретация сектора ХАРАКТЕР (Тип восприятия) на основе количества единиц
- `get_energy_interpretation()` - интерпретация сектора ЭНЕРГИЯ на основе количества двоек (созависим с сектором Здоровье)
- `get_interest_interpretation()` - интерпретация сектора ИНТЕРЕС на основе количества троек
- `get_health_interpretation()` - интерпретация сектора ЗДОРОВЬЕ на основе количества четверок (созависим с сектором Энергия)
- `get_logic_interpretation()` - интерпретация сектора ЛОГИКА на основе количества пятерок (созависим с сектором Память)
- `get_labor_interpretation()` - интерпретация сектора ТРУД на основе количества шестерок (созависим с сектором Удача)
- `get_luck_interpretation()` - интерпретация сектора УДАЧА на основе количества семерок (созависим с сектором Труд)
- `get_duty_interpretation()` - интерпретация сектора ДОЛГ на основе количества восьмерок (сочетается с сектором Характер)
- `get_memory_interpretation()` - интерпретация сектора ПАМЯТЬ на основе количества девяток (созависим с сектором Логика)
- `get_all_interpretations()` - получает все интерпретации для результатов расчетов
- `get_life_interpretation()` - интерпретация сектора БЫТ на основе коэффициента сектора Быт (4/5/6)
- `get_temperament_interpretation()` - интерпретация сектора ПЛОТСКОЕ (Темперамент) на основе коэффициента сектора Темперамент (3/5/7)
- `get_family_interpretation()` - интерпретация сектора СЕМЬЯ на основе коэффициента сектора Семья (2/5/8)
- `get_stability_interpretation()` - интерпретация СТАБИЛЬНОСТЬ на основе коэффициента сектора Цель (1/4/7)
- `get_purpose_interpretation()` - интерпретация ЦЕЛЕУСТРЕМЛЕННОСТЬ на основе коэффициента сектора Цель (1/4/7)
- `get_transformation_interpretation()` - интерпретация ТРАНСФОРМАЦИЯ на основе секторов Характер, Долг, Труд и Удача
- `get_destiny_number_interpretation()` - интерпретация ЧИСЛА СУДЬБЫ (профессиональный вектор)
- `get_additional_qualities()` - получает все интерпретации дополнительных качеств для результатов расчетов

## Алгоритм расчетов

1. **Первое дополнительное число**: Сумма всех цифр даты рождения (например, 18.08.1984 → 1+8+0+8+1+9+8+4 = 39)

2. **Второе дополнительное число**: Сумма цифр первого дополнительного числа (39 → 3+9 = 12)

3. **Третье дополнительное число**: Первое дополнительное - (2 × первая цифра даты). Если первая цифра 0, берется первая ненулевая цифра (39 - (2×1) = 37)

4. **Четвертое дополнительное число**: Сумма цифр третьего дополнительного числа (37 → 3+7 = 10)

5. **Матрица**: Заполнение секторов 1-9 числами из даты и всех дополнительных чисел. Каждое число попадает в соответствующий сектор (1 в сектор 1, 2 в сектор 2 и т.д.)

6. **Сектор темперамент**: Количество цифр в секторах 3/5/7

7. **Сектор быт**: Количество цифр в секторах 4/5/6

8. **Сектор цель**: Количество цифр в секторах 1/4/7

9. **Сектор семья**: Количество цифр в секторах 2/5/8

10. **Число Судьбы**: Сумма всех цифр даты рождения. Если при суммировании получается 11, останавливается и возвращает 11 (мастер-число). Иначе приводится к однозначному числу (например, 38 → 3+8=11 → останавливается на 11; 39 → 3+9=12 → 1+2=3)

## Зависимости

- **aiogram 3.24.0** - асинхронный фреймворк для Telegram Bot API
- **python-dotenv 1.2.1** - загрузка переменных окружения из .env файла

## Поток данных

1. Пользователь отправляет дату рождения в формате DD.MM.YYYY
2. Обработчик `process_date()` получает сообщение
3. Вызывается `calculate_all()` из модуля `numerology.py`
4. Выполняются все расчеты согласно алгоритму
5. Вызывается `get_all_interpretations()` из модуля `interpretations.py` для получения интерпретаций секторов
6. Результаты форматируются функцией `format_results()` с включением интерпретаций
7. Основной отформатированный ответ отправляется пользователю первым сообщением
8. Вызывается `get_additional_qualities()` из модуля `interpretations.py` для получения дополнительных качеств
9. Дополнительные качества форматируются функцией `format_additional_qualities()`
10. Отформатированные дополнительные качества отправляются пользователю вторым отдельным сообщением
